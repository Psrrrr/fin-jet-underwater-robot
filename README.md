# fin-jet-underwater-robot
Bill of materials and hardware documentation for a four-limb underwater robot with fin-like propulsors and pulsed-jet assistance.
Please refer to the 3D model files for detailed 3D-printable models and robot parameters.
Supplementary Material for IEEE Robotics and Automation Letters article "Design and Analysis of a Four-Limb Underwater Robot with Fin-Like Propulsors and Pulsed-Jet Assistance".
